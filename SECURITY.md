# Segurança e dados pessoais

Não envie chaves de API, senhas, tokens, arquivos `.env`, bancos da agenda,
gravações do microfone ou dados de uma conta em issues, pull requests ou anexos
públicos. Remova dados pessoais dos exemplos e dos logs antes de compartilhá-los.

As contas do Apolo são locais. Senhas não são armazenadas; os dados do cofre são
criptografados com uma chave derivada da senha. Preferências, agenda, logs e caches
operacionais não recebem essa mesma criptografia. Mantenha as permissões do
Windows e um backup do perfil.

O reconhecimento por voz e a IA podem usar serviços de rede, conforme o motor
selecionado. Confira o README antes de gravar informações privadas.

Comandos de sistema são limitados à lista permitida. Desligar e reiniciar pedem
confirmação. O modelo de IA não recebe autorização para executar código
arbitrário. O WhatsApp prepara a conversa para envio manual.

Para relatar uma vulnerabilidade, use o recurso privado **Report a vulnerability**
na aba **Security** do GitHub, se estiver habilitado. Se esse canal não estiver
disponível, abra somente uma issue genérica solicitando contato privado, sem
publicar detalhes de exploração ou credenciais.
